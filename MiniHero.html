Mini Hero

Unreal Engine Blueprint

Project Overview

A 2D pixel-art action platformer where players progress through handcrafted levels while avoiding deadly traps and defeating hostile enemies.The game focuses on tight controls, responsive combat, and increasing difficulty, offering a classic retro experience with modern gameplay polish.Each level introduces new challenges such as moving hazards, enemy attack, and precision jumps, encouraging players to learn, adapt, and master the mechanics.

  • Implemented player movement, combat, and health systems.
  • Created enemy behavior logic and attack mechanics.
  • Designed level layouts, traps, and progression flow.
  • Built UI elements (health, menus, controls).
  • Optimized performance for smooth gameplay on low-end systems.

  • Handled game logic, assets integration, and testing.

Technical Implementation

AI Systems

    State-Based Enemy AI :
  • Implemented a structured AI system with clearly defined states including Idle, Patrol, Chase, Attack, and Death.
    • Enemy Patrol & Positioning :
  • Enemies patrol predefined paths or hold defensive positions to create varied and dynamic encounters.
    • Detection & Combat Behavior :
  • Enemies detect the player using proximity checks and line-of-sight detection.
  • Once engaged, enemies transition into chase and attack behaviors with controlled movement and targeting.
    • Attack Logic & Balance :
  • Used attack cooldowns and damage timers to ensure fair, balanced, and predictable combat.
  • Enemies stop, aim, and attack with configurable accuracy and attack intervals.
    • Damage & Death Handling :
  • Enemies react to player attacks, take damage, and trigger death sequences.
  • Death handling includes animation playback, collision disabling, memory cleanup, and kill-count updates for level completion checks.
    • Behavior Implementation:
  • Built entirely using Blueprint logic, AI Controllers, and event-driven systems, ensuring maintainability and scalability.

Weapon Framework

    Modular Weapon System :
  • Designed a flexible and extendable weapon framework that supports multiple attack types.
    • Melee Combat Implementation :
  • Implemented melee attacks with accurate hit detection using collision and overlap events.
    • Damage System :
  • Damage is applied through event-based collision detection and health reduction logic.
  • Both enemies and the player share a common health and death system.
    • Animation Synchronization :
  • Attack animations are precisely synced with damage frames to improve combat feedback.
    • Extensibility :
  • Framework is easily extendable to support new weapons, abilities, and power-ups.

Performance & Optimization

    Blueprint Optimization :
  • Reduced unnecessary Tick usage and shifted logic to event-driven execution.
    • AI & Collision Efficiency :
  • Optimized collision checks and AI evaluations for smoother gameplay.
    • Rendering Optimization :
  • Used lightweight pixel sprites and efficient animations to reduce rendering overhead.
    • Gameplay Area Optimization :
  • Limited enemy logic execution to active gameplay zones only.
    • Memory Management :
  • Ensured proper cleanup of enemies after death to avoid memory leaks.
    • Frame Rate Stability :
  • Maintained consistent and stable frame rates across all levels, even during combat-heavy sequences.
