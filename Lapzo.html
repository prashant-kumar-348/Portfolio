Lapzo

Unreal Engine Blueprint

Project Overview

Lapzo is a 3D car racing game developed using Unreal Engine 5, focused on vehicle handling, AI-driven racing, and core gameplay systems. The game features car selection, AI opponents, lap-based progression, and a custom-designed track with interactive elements like speed boosters. It emphasizes smooth controls, structured game flow, and a complete playable racing experience.
